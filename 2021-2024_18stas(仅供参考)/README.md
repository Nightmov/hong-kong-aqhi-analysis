

## 实际发现

602,167条记录纳入主分析，覆盖率95.41%。K=2轮廓系数0.609；较高风险组为塔门、屯门、东涌、元朗，站点等权风险比例2.82%，另一组1.31%。两组采用钟点17时风险最大，秋季均值最高。平日/周末差异的各站95%月份块区间均含0。

85%的月份块重抽完全复现合并窗口的分组，但前后两个两年窗口分类不同，因此不能把分组称为永久污染分区。K=3评分接近且产生单站组，不能宣称K=2是唯一正确模型。




## 运行方法（当前上传目录）

此目录仅保留分析和独立验证脚本，供参考；最终采用的是相邻的2014—2024年15站版本。

在本目录打开终端：

```powershell
python -m pip install -r requirements-lock.txt
python -B -X utf8 src/analyze.py
python -B -X utf8 src/validate_outputs.py
```

默认输入路径为`../../处理后数据/处理后数据`，以本目录中的config.json为基准。该文件夹需包含成员2的`aqhi_long.csv`、`stations.csv`和`长表字段说明.txt`；输入在其他位置时修改配置即可。脚本不修改输入文件，结果写入本目录的results。

当前验证包含144个特征重算和数据一致性检查，不依赖串并行实验。results中保留的历史并行文件不参与当前运行流程。
